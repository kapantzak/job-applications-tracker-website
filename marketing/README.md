# Marketing kit

Assets for product listings. Not part of the website build.

| File | Spec | What it is |
|---|---|---|
| `logo.png` | 500×500 PNG, ≤15 MB | The Lens mark from `public/favicon.svg` on a full-bleed `#7c3aed` square |
| `covers/01-hero.png` | 1200×630 PNG, ≤15 MB | The site's Open Graph image (`scripts/og/og.html`) |
| `covers/02-jobs.png` | 1200×630 PNG, ≤15 MB | "Your agent finds jobs, the app checks every link" + Jobs screen |
| `covers/03-review.png` | 1200×630 PNG, ≤15 MB | "Sync Gmail, review what it found" + Review screen |
| `covers/04-dashboard.png` | 1200×630 PNG, ≤15 MB | "See where everything stands" + Dashboard screen |
| `demo.mp4` | ≤100 MB | Copy of `public/media/demo.mp4` (1:30, 1440×900, H.264, no audio, burned-in captions) |

## Regenerate

```sh
npm run marketing
```

Requires `ffmpeg` on `PATH` and the Playwright Chromium (`npx playwright install chromium`).
The script fails if any file exceeds its size limit.

Regenerate after changing:

- the copy in `src/content/site.ts` (cover headlines and the npx command come from there),
- `scripts/og/og.html` (cover 1),
- `public/media/demo.mp4` (screenshots and the video copy). A new recording needs new frame
  times and crops in `scripts/marketing/render.mjs`: pick moments where the cursor is outside
  the crop and keep the crop above the burned-in captions.

## Decisions

1. Location: `marketing/` at the repo root, not `public/`, so it is not deployed.
2. Logo: full-bleed square without rounded corners or transparency; listing sites apply their own rounding or circle crop.
3. Covers: hero, then the Jobs, Gmail review and Dashboard journey steps. Headlines are the journey step titles from `site.ts`.
4. Screenshots: frames of the 0.3.0 demo video (real app UI, invented data), cropped to exclude the sidebar cursor and captions.
5. Video: the site's demo video, copied as is.
6. Everything is generated by `scripts/marketing/render.mjs` so the kit can be rebuilt when the copy or the app changes.
